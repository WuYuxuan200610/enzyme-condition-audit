# LLM 基准提示词（可复现）

金标签见 `llm_benchmark_cases.json`（真冲突 = {1,7,10}，其余为非真冲突）。

评测三个配置在相同 10 组证据对上的判定，均要求输出严格格式 `序号|是/否|理由`：

- **B0 白板 Agent**：只给"判断是否真矛盾"，不给任何条件规则。
- **B1 简单 Prompt**：只加一句"pH 差 >1 或温度差 >10°C 就不判矛盾"。
- **B2 本 Skill**：给完整 R0–R7 规则链与裁决逻辑。

## 共享证据对（同一种酶 α，参数 Km）

1. A: Km=5 mM，pH 7.0，25°C，大肠杆菌表达，Tris-HCl；B: Km=50 mM，pH 7.0，25°C，大肠杆菌表达，Tris-HCl
2. A: Km=5 mM，pH 6.0，25°C，大肠杆菌，Tris-HCl；B: Km=50 mM，pH 8.0，25°C，大肠杆菌，Tris-HCl
3. A: Km=5 mM，pH 7.0，30°C，大肠杆菌，Tris-HCl；B: Km=50 mM，pH 7.0，50°C，大肠杆菌，Tris-HCl
4. A: Km=5 mM，pH 7.0，25°C，大肠杆菌表达；B: Km=50 mM，pH 7.0，25°C，酿酒酵母表达
5. A: Km=5 mM，底物 X，pH 7.0，25°C；B: Km=50 mM，底物 Y，pH 7.0，25°C
6. A: Km=5 mM，野生型，pH 7.0，25°C；B: Km=50 mM，N 端 His-tag 融合，pH 7.0，25°C
7. A: Km=5 mM，pH 7.0，25°C；B: Km=50 mM，pH 7.2，25°C
8. A: Km=5 mM，pH 7.0，25°C；B: Km=6 mM，pH 7.0，25°C
9. A: Km=5 mM，pH 6.0，30°C；B: Km=50 mM，pH 8.0，50°C
10. A: Km=5 mM，pH 7.0，25°C；B: Km=50 mM，pH 7.0，30°C

## B0 白板 Prompt

```
你是文献矛盾检测助手。请判断下面每组"两条酶学证据"是否构成【真矛盾】。
<10 组证据对>
严格只输出 10 行，每行格式：`序号|是/否|一句话理由`。
```

## B1 简单 Prompt

```
你是文献矛盾检测助手。请判断下面每组是否构成【真矛盾】。
一个简单提示：如果两条证据的 pH 相差超过 1.0，或温度相差超过 10°C，
就视为"实验条件不同"，不要判为矛盾。
<10 组证据对>
严格只输出 10 行，每行格式：`序号|是/否|一句话理由`。
```

## B2 本 Skill Prompt

```
你是文献矛盾检测助手。必须严格按「酶学实验条件可迁移性规则」先做条件可比性裁决：
R0 酶形式/底物不同→不可比；R1 宿主不同→不可比；
R2 缓冲液类别不同且 pH 不重叠→不可比，仅类别不同→需复核；
R3 |ΔpH|>1.0→不可比，0.5<|ΔpH|≤1.0→需复核，≤0.5→可比；
R4 |ΔT|>10°C→不可比，≤10°C→可比；
R5 底物浓度比>10×→需复核；R6 辅因子显著不同→需复核；R7 表观vs真值混比→不可比。
裁决：任一不可比→整体不可比(不判真矛盾)；有需复核→部分可比(默认不判)；
全部可比且数值差>3倍→才判真矛盾。
<10 组证据对>
严格只输出 10 行，每行格式：`序号|是/否|一句话理由`。
```
